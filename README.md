# Exists or New

CS424 Program Reasoning의 equivalence reduction을 체험하는 웹 퍼즐 게임입니다.

- 기록 속 두 식을 +, −, ×로 조합한 후보를 판정합니다.
- 공개된 모든 입력에서 같은 출력을 내는 기존 식이 있으면 ∃, 없으면 +를 누릅니다.
- 같은 출력을 내는 식은 더 짧은 대표 하나만 남기며, 길이가 같으면 기존 대표를 유지합니다. 버린 식은 복원하지 않습니다.
- 3목숨·무제한 라운드이며, 오답이나 시간 초과로 목숨을 잃습니다.
- 6라운드마다 상수, 10라운드마다 입력이 추가됩니다.
- 제한 시간과 변수 개수는 직접 설정할 수 있습니다.

동치는 현재 공개된 입력을 기준으로 하며, 모든 실수에서의 수학적 항등성을 뜻하지 않습니다.
