# Exists or New

CS424 Program Reasoning의 equivalence reduction을 소재로 한 웹 퍼즐 게임입니다.

- 변수 1~3개를 선택합니다. 처음 3×3 목록에는 선택한 변수들만 있습니다.
- 현재 입력에서 후보와 결과가 같은 목록의 식을 누르면 둘 다 사라집니다. 같은 결과가 없으면 **+**로 후보를 추가합니다.
- 오답이거나 목록이 가득 차면 후보가 대기 큐로 돌아갑니다. 대기 중인 식이 5개가 되면 게임이 끝납니다.
- 새 후보 유입은 10초에서 최소 3초, 입력 교체는 20초에서 최소 10초까지 각각 0.5초씩 빨라집니다. 큐를 비우면 다음 후보를 바로 가져옵니다.
- 입력은 −5~5 정수입니다. 식은 변수·목록·대기 식을 +, −, ×로 조합하며, 생성 시 20% 확률로 상수 하나를 재료에 섞습니다.
- 판정은 현재 입력에서의 관찰 동치이며, 모든 실수에서 성립하는 항등성을 뜻하지 않습니다.

튜토리얼과 KR/EN 전환을 지원합니다. 최고 점수는 변수 개수별로 이 브라우저에 저장됩니다.
